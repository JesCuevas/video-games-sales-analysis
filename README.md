# 🎮 Análisis exploratorio de ventas globales de videojuegos

## 📌 Descripción del proyecto
Este proyecto realiza un Análisis Exploratorio de Datos (EDA) sobre el mercado global de videojuegos. El objetivo es identificar patrones de consumo, determinar el comportamiento de las ventas por regiones (Norteamérica, Europa, Japón y Resto del Mundo), evaluar la relevancia de las plataformas a lo largo del tiempo y analizar los géneros más populares.

---

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Python 3.x
* **Librerías:** `pandas`, `numpy`, `matplotlib`, `seaborn`
* **Entorno:** Jupyter Notebook / VS Code

---

## 🔍 Hallazgos
* Se analizaron **16,598 registros**, de los cuales **11,493 corresponden a videojuegos únicos** distribuidos en 12 géneros y 31 plataformas.
* **Picos históricos:** Las ventas globales alcanzaron su punto máximo entre los años 2006 y 2011, experimentando una tendencia bajista a partir de 2013.
* **Distribución Geográfica:** Norteamérica y Europa concentran la mayor cuota del mercado global.
* **Géneros Top:** Los géneros con mayor volumen de ventas globales son **Acción**, **Sports** y **Shooter**.
* **Plataformas Líderes:** Las consolas con mayores ventas históricas acumuladas son **PS2**, **Wii** y **X360**.
* **Títulos más Vendidos (1980–2020):** **Wii Sports**, **Super Mario Bros.** y **Grand Theft Auto V**.
